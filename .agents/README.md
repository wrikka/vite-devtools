# .agents/ — machine state for this workspace

JSON is the source of truth; everything here is generated by `scripts/state.ts`
(absolute path: `D:/dot-agents/scripts/state.ts`, use `--root <dir>` for other
projects). Never hand-edit generated files — the veto hook denies it.

## Read order for agents

1. `state.md` — human summary: health, git, loop results, projects rollup
2. `state.json` — snapshot: blocks with provenance (at/source), derived.health
3. `requests.json` — what the user asked for + status (new/in-progress/done/
   dropped/blocked); `new` older than 24h auto-becomes `blocked`
4. `activity.json` — event feed (telemetry); `journal/` is the raw append-only log;
   `archive/<doc>-YYYY-MM.json` — items that aged out of any ring buffer
5. `todos.json`, `decisions.json`, `incidents.json` — curated records
6. `sessions/<harness>/<id>.json` — per-session rollups; `runs/<date>/` — per-run detail

## Commands

```powershell
bun D:/dot-agents/scripts/state.ts view                 # quick summary
bun D:/dot-agents/scripts/state.ts summary              # same, as JSON
bun D:/dot-agents/scripts/state.ts watch                # auto-compact journal (background)
bun D:/dot-agents/scripts/state.ts check --strict       # health gate (CI use)
bun D:/dot-agents/scripts/state.ts request list         # open user requests
bun D:/dot-agents/scripts/state.ts request done <id>    # close a request
bun D:/dot-agents/scripts/state.ts todo add "<title>"   # queue a task
bun D:/dot-agents/scripts/state.ts db && state.ts query "select kind, count(*) from events group by kind"
```

## Rules

- Missing data stays absent/null — never guess values
- `derived.*` is computed — do not write it
- `activity.md` is the human narrative — agents may append summaries there
- Hooks append to `journal/*.jsonl`; `compact` promotes to the docs above
